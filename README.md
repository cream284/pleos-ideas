# Pleos Idea Notes

태블릿 브라우저에서 읽는 차량용 앱 공모전 아이디어 문서입니다.

**문서 열기: https://cream284.github.io/pleos-ideas/**

## 구성

- `index.html`: 네 후보 목록과 심사 기준 비교표
- `ideas/group-trip.html`: 여러 차, 한 여행
- `ideas/easy-route.html`: 내게 편한 길
- `ideas/rental-return.html`: 반납 전, 한 번에
- `ideas/field-service.html`: 방문 업무, 차에서 연결
- `assets/style.css`: 반응형·발표형 문서 및 인쇄 스타일
- `.nojekyll`: 정적 파일 그대로 게시

각 상세 문서는 문제, 경험, 기술, 사업, 심사, MVP의 6개 장으로 구성됩니다. 목차와 이전/다음 링크로 이동합니다. 브라우저 인쇄 기능에서 PDF로 저장할 수 있습니다. 별도 PDF 파일을 사전 생성한 것은 아닙니다.

## 수정 및 배포

프레임워크·JavaScript·빌드·서버가 없습니다. HTML/CSS를 수정해 `main`에 커밋하면 GitHub Pages가 반영합니다. 게시 원본은 `main` 브랜치의 `/ (root)`입니다.

## 근거 및 해석

2026-10-26 공식 문서 확인 기준입니다. 공식 심사 항목의 세부 배점은 비공개이고 2차 PT 기준은 추후 안내입니다. 아이디어 우선순위와 고객·과금 모델은 팀 검토 가설이며, 공개 API의 문서 존재와 실제 실행 검증은 구분합니다. 각 문서 하단의 공식 출처를 참고하세요.

공개 검토 문서이므로 개인 정보·프로젝트 인증키·고객 자료는 포함하지 않습니다.
