Evidence / 02

확인된 기준과 남은 가설

공식 심사 기준

1차는 차량특화성·창의성·기술 활용성·사업성을 평가합니다. 세부 배점은 비공개이며 2차 PT 기준은 추후 안내입니다.

시연 영상과 소스·APK 등 개발 산출물에 단계별 가산점이 있습니다. 이 HTML 자료 자체는 동작하는 차량 앱의 개발 산출물을 대체하지 않습니다.

API 사용 원칙

Vehicle State·NaviHelper를 핵심 검증 대상으로 삼습니다. FusedLocation·음성·제어는 사용 신청 안내의 준비 중 표시와 실제 접근 상태를 확인합니다.

문서에 API가 존재해도 차종·권한·capability·실행 환경에서 검증해야 합니다. UWB는 공개 API를 확인하지 못해 핵심 전제에서 제외했습니다.
