01 / IDEA STUDY

우리가 만들고 싶은 변화.

01

현장은 끝났는데, 보고는 아직 시작도 못 했다.

작업자가 확인한 기록을 모아 보고 초안으로. 하루의 끝을 돌려줍니다.

02

반납 시간은 다가오는데, 충전 조건과 입구가 헷갈린다.

해야 할 일이 보이면 불안이 준비로 바뀝니다. 여행의 끝에도 좋은 기억을 남깁니다.

03

우리 차는 쉬고 싶은데, 다른 차에 또 연락하기 망설여진다.

서로의 필요를 알고 함께 결정합니다. 같은 속도보다 같은 마음으로 여행합니다.

02 / DECISION TABLE

같은 기준으로, 세 후보를 비교합니다.

후보현실적인 MVP사업 가설우선 확인
방문 업무, 차에서 연결오늘의 방문 목록 → 다음 방문 안내 → 정차 후 완료·보류 → 메모와 보고 초안서비스 업체의 차량당 구독 가설. 중복 입력과 보고 부담의 감소를 실제 업무에서 검증합니다.휴대폰 업무 앱보다 나은 이유를 증명
렌터카 반납, 마음 편하게계약 조건 직접 입력 → 현재 배터리 비교 → 충전소·반납 입구 선택 → 준비 체크리스트렌터카 운영사 대상 차량당 이용료 가설. 반복 문의와 반납 준비 혼선을 줄이는 가치부터 검증합니다.운영사 계약 조건 확보와 제휴 의향 확인
차는 달라도, 여행은 함께공유 동의·그룹 참여 → 휴식·충전 필요 표시 → 후보 장소에 합의 → 각 차량의 내비 안내여행 그룹 이용권·렌터카 제휴 가설. 일회성 여행 수요이므로 월 구독보다 반복 사용과 제휴 가능성을 먼저 확인합니다.두 앱 인스턴스와 외부 서버 통신 검증

방문 업무·렌터카 반납은 작은 범위로 검증을 시작할 후보입니다. 함께 여행은 두 앱과 서버의 통신을 먼저 입증합니다. 이 순서는 수상 가능성 점수가 아닌 검증 순서입니다.

03 / IDEA STUDY

기술을 많이 쓰기보다, 필요한 곳에.

공개 SDK 5종을 설계에 검토하되, 사용 권한과 실제 실행은 별도 확인합니다.

VehicleNaviFused LocationSTTTTS

현재 MVP에서 제외

Gleo 인터페이스, UWB 위치 인식, VisionPulse 연동, 자동 결제. 공개 예정이라는 추정도 확정 기능으로 쓰지 않습니다.

외부 통신은 실증 필요

공식 가이드는 셀룰러·Wi-Fi와 외부 서버 사용을 전제합니다. 차량별 연결 제공, 앱 권한, HTTPS 요청과 연결 끊김 복구를 확인해야 합니다.

04 / IDEA STUDY

휴머니티를 향한 진보.

Progress for Humanity

현대자동차의 브랜드 비전. 우리의 제안에서는 ‘사람의 시간, 마음, 관계를 배려하는 경험’으로 해석합니다.

방문 업무, 차에서 연결

일하는 사람을 배려합니다. 감시 지표보다 기록의 누락과 중복 입력을 줄이는 데 집중합니다.

렌터카 반납, 마음 편하게

불확실성을 줄이는 배려입니다. 숨은 조건 없이 현재 상태와 사용자가 확인할 일을 보여줍니다.

차는 달라도, 여행은 함께

관계를 위한 연결입니다. 다른 차의 필요를 존중하고 위치 공유와 만남에 대한 선택권을 남깁니다.

공식 비전과 팀의 해석을 구분합니다. 브랜드 정합성을 별도의 공식 심사 가산점으로 주장하지 않습니다.

05 / IDEA STUDY

심사위원에게 보여줄 증거.

차량특화성

왜 차량 안이어야 하는가

차량 상태와 내비가 연결될 때 사라지는 번거로움을 보여줍니다.

창의성

새 기능보다 새로운 연결

기존 서비스와 비교해 사용자 경험이 달라지는 장면을 증명합니다.

기술 활용성

완결된 시연과 실패 대응

실제 SDK 값, 사용자 확인, 상태 변화와 오류 처리를 보여줍니다.

사업성

지불할 고객과 반복되는 가치

현장 인터뷰와 도입 의향으로 사업 가설을 좁힙니다.

공식 세부 배점은 비공개로 검토. 임의 배점·레이더 점수·근거 없는 시간 절감 수치는 사용하지 않았습니다.
