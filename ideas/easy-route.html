문제와 첫 고객

초보·복귀 운전자는 복잡한 합류, 좁은 진입로, 급한 차선 변경 구간을 반복해서 만나곤 합니다. 빠른 길과 자신에게 편한 길이 항상 같지는 않습니다.

먼저 만날 사용자

초보·복귀 운전자와 운전 교육기관. 사용자에게 필요한 기간에 집중적으로 쓰는 상품이라는 가설.

현재의 해결 방법

어려웠던 구간을 기억해 두거나 다음 이동 때 동승자에게 우회 방법을 묻습니다.

문제의 강도와 빈도는 아직 검증하지 않았습니다. 인터뷰에서는 최근 실제 사례와 현재의 대처 방법부터 확인합니다.

차량 화면에서 이어지는 경험

정차 후 어려운 구간을 직접 표시하면, 다음 동일 목적지 이동에서 해당 구간을 덜 거치는 검증된 후보를 설명합니다.

01

정차 후 기록
최근 경로 중 운전자가 직접 어려웠던 구간과 이유를 선택합니다.

02

선호 저장
골목·복잡한 합류 등 사용자가 선택한 사유와 도로 구간을 연결합니다.

03

대안 확인
자체 경로 엔진이나 외부 지도에서 회피 가능한 대안을 계산하고 우회 시간·적용 한계를 보여줍니다.

04

내비에 전달
검증된 경유지로 안내를 요청한 뒤 반환 경로가 실제 의도한 구간을 피하는지 확인합니다.

02 / 04 — 06

누가, 왜 계속 사용하는가

사업 가설

초보 운전 기간 이용권과 운전 교육기관의 수강생 지원 상품을 우선 검토합니다. 개인의 장기 월 구독 유지율은 미검증입니다.

고객 검증에서 볼 것

반복해서 피하고 싶은 도로가 있는지, 허용 우회 시간은 얼마인지, 추천 경로 실제 채택률과 다음 이동 재사용을 확인합니다.

가격·시장 규모·MAU·유지율은 조사 전 임의 수치를 넣지 않았습니다. 구독 모델 자체가 공식 가산점이라는 근거도 없습니다.

3인 팀이 먼저 증명할 것

최소 구현 범위

검증된 구간 3곳과 대체 경로를 준비하고, 정차 후 구간 표시 → 다음 경로 후보 제안 → 안내 요청을 구현합니다.

시연 장면

같은 출발·목적지에서 기본 안내와 개인 선호 적용 후보를 비교하고, 우회 구간 및 추가 시간을 보여줍니다. 고정 예제는 고정 예제로 명시합니다.

가장 큰 불확실성

방향지시등·브레이크만으로 불안이나 위험을 판정하지 않습니다. 경유지 추가만으로 회피가 보장되지 않으므로 결과 검증 실패 시 추천을 중단합니다.
