# 현대자동차그룹 차량용 앱 개발 공모전 온라인 설명회 분석

- 원본: `pleos-live.mp4` (53분 50초)
- 분석 기준: 2026-10-28 온라인 설명회 음성. 자동 전사 초안을 바탕으로 정리했다. 고유명사·수치·세부 권한은 공식 문서와 실제 개발 환경에서 재확인이 필요하다.
- 전사 원문: `transcript-base-ko.txt` — 자동 인식본이므로 인명·SDK 표기는 본 문서 기준으로 사용한다.

## 결론: 우리 팀의 기획에 바뀌는 전제

1. **외부 API 사용과 공용 인터넷 연결은 가능하다.** 운영진이 기술 Q&A에서 직접 답했다(49:06). 따라서 장소·시설·예약·제휴 서비스와 연동하는 B2B/B2C 구상은 공모전 개발 범위 안에서 검토할 수 있다.
2. **실차 시연은 지원하지 않으며 Pleos Connect Emulator로 검증한다**(32:24, 44:57). 차량 하드웨어나 실차 전용 센서를 전제로 한 기능은 제출 핵심으로 삼으면 안 된다.
3. **공개 SDK 5종은 개발 단계에서 별도 승인 없이 권한 선언으로 사용할 수 있다고 안내했다**(49:33). Vehicle, NaviHelper, STT, TTS, Fused Location이다. 앱마켓 실제 배포 단계의 권한 심사는 별도다.
4. **SDK 개수 자체보다 핵심 경험에 대한 적절한 활용이 중요하다.** 고객 문제의 핵심 흐름에 필요한 SDK를 고르고, 그 연결을 시연으로 보이는 것이 중요하다고 명확히 말했다(43:20).
5. **1차에도 작동 산출물은 가산점이고, 2차 PT에서는 실제 동작 앱이 필수다**(18:32, 46:54). 따라서 11월 15일에는 한 가지 차량 특화 경험을 확실히 구현한 APK·GitHub·짧은 시연 영상을 내는 전략이 유리하다.

## 추가 확인이 필요한 발표 내용

37:07–37:30 부근에는 미공개 SDK 제공 계획으로 들리는 발언이 있다. 자동 전사만으로 정확한 범위를 확정하기 어려우므로, 공개 SDK 5종 외 기능이 이미 사용 가능하다는 근거로 해석하지 않는다. 추가 SDK 목록·제공 시기·Emulator 지원은 공식 공지로 확인한다.

| SDK / 환경 | 이번 설명회에서 확인된 활용 | 우리 기획에 적용할 방식 | 피해야 할 주장 |

| Vehicle SDK | 차량 상태, 주행, 배터리·충전, 공조; 일부 차량 기능 제어는 권한 범위에 따름 | 배터리/충전 상태와 현장 도착 준비·EV 업무 동선 연결 | 모든 차량 제어가 가능하다고 단정 |

## 현재 후보의 우선순위 재판정

### 1. 현장 도착 보장 도우미 — 유지하되 이름과 약속을 조정

- **권장 명칭:** `현장 도착 준비 도우미`
- **강점:** Vehicle(배터리/충전 상태) + NaviHelper(목적지/경로) + Fused Location(도착 맥락) + STT/TTS(짧은 안내)로 완결된 흐름을 만들 수 있다. 외부 API 허용으로 현장 작업·예약·고객 안내 연동도 가능하다.
- **수정:** 교통·현장 변수를 통제할 수 없으므로 ‘도착 보장’ 대신 `도착 전 준비 누락을 줄인다`로 문제를 정의한다.
- **Emulator 데모:** 충전량 저하 또는 출발 지연 상태 변경 → 재계산/대안 경로 → TTS 확인 → 방문처 준비 메시지(모의 외부 API).

### 2. 도착을 준비하는 차 2.0 — 조건부 유지

- **강점:** 도착 반경과 차량 내비 흐름을 써서 호텔·리조트·오피스가 손님을 맞이할 시간을 만든다는 감성·사업성 메시지가 좋다.
- **핵심 위험:** UWB 정밀 위치, 자동 결제, 시설 제어를 현재 공개 SDK 기능처럼 말하면 안 된다.
- **Emulator 데모:** NaviHelper 목적지와 Fused Location 기반 도착 임박 → TTS로 수신 동의 → 외부 API에 ‘예상 도착’ 전송 → 시설 준비 상태를 차량 화면에 표시.

### 3. EV 출장·현장업무 에너지 플래너 — 구현 우선 후보

- **강점:** 안내에서 직접 예시로 든 ‘배터리 상태와 이동 경로 결합’과 가장 가깝다. 차량 특화성과 구현 가능성이 선명하다.
- **차별화 조건:** 단순 충전소 추천이 아니라 `현장 업무 약속을 지키기 위한 에너지 의사결정`으로 좁힌다. 기업 구독은 방문 일정·차량 운영 현황 대시보드로 확장한다.
- **Emulator 데모:** Virtual Console의 충전 상태 변경 → 방문 일정 유지 가능성 판단 → 충전 경유지 제안 → NaviHelper 경유지 설정 → TTS 안내.

## 발언의 해석 범위

이 영상은 공모전 개발·평가 방향의 공식 설명이다. 다만 Vehicle SDK의 개별 도메인, 권한, 앱마켓 배포 심사는 문서와 실제 프로젝트 설정을 다시 확인해야 한다. ‘외부 API/공용 네트워크 가능’은 해당 연결 자체의 허용을 뜻하며, 결제 사업자·개인정보·시설 제어 권한까지 자동 승인한다는 뜻은 아니다.
